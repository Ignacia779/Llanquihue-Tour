# Llanquihue Tour

👤 Autor del proyecto
Nombre completo: Ignacia Llanos 
Carrera: Analista Programacion Computacional


Proyecto desarrollado en Java para gestionar información de tours turísticos.

* Lectura de datos desde un archivo de texto (.txt).
* Carga de tours en una colección ArrayList.
* Visualización del catálogo completo de tours.
* Filtrado de tours por tipo (Aventura).

Estructura del proyecto

* model: contiene la clase Tour.
* data: contiene la clase GestorDatos.
* ui: contiene la clase Main.
* resources: contiene el archivo tours.txt.

## Tecnologías utilizadas

* Java
* IntelliJ IDEA
* Git y GitHub
